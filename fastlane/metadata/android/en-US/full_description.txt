FrostKeys Lineage is an experimental, unofficial development fork of FrostKeys. It aims to move the keyboard core to LineageOS LatinIME while preserving useful local features where they can be ported.

This development build removes Gemini AI, Klipy, remote GIF search and sticker sending. It is not the official FrostKeys application and is not a release from the original maintainer.

The branch retains or is working to retain local keyboard features such as multilingual typing, custom themes, Frosted Glass effects, emoji search, a local clipboard, custom dictionaries, glide typing, and backup and restore.

Migration work is ongoing. The full LineageOS LatinIME port and feature parity have not yet been completed. Builds from GitHub Actions are development artifacts; review their source and permissions before installation. The application uses a separate package ID so it can be installed alongside the original FrostKeys.

FrostKeys Lineage is open source and preserves upstream license notices. This fork is not affiliated with or endorsed by LineageOS, HeliBoard, or the original FrostKeys maintainer.
